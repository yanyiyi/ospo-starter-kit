開放原始碼軟體（Open Source Software，以下稱「OSS」）在現代軟體開發中已不可或缺。
[公司名稱] 業務中每天使用的 [主要使用技術（例如：雲端基礎架構、行動應用程式的 UI 框架、資料分析平台）] 大多也是以 OSS 為基礎。
這些 OSS 也是全世界開發者匯聚智慧與經驗、為解決共同課題而長期累積的成果。
理解並適切運用 OSS，正逐漸成為開發者與管理階層的重要技能。

本文件將分別從開發者與管理階層的視角，詳細說明運用 OSS 所能獲得的代表性效益。

## 對開發者的效益

運用 OSS 能讓開發者享有許多效益。
以下舉出幾個特別重要的重點加以說明。

1. **避免重新發明輪子，專注於有價值的開發**

    開發新服務或新功能時，並不需要從零打造一切。
    例如 [公司名稱] 日常使用的 [自家公司使用的 OSS 範例（例如：Web 框架或資料庫連線程式庫）]，都是全世界開發者長年改良、可靠性與效能已獲驗證的 OSS。

    如果不使用這些 OSS，而是全部自己從頭打造，會怎麼樣呢？
    你將被資訊安全措施、效能調整、錯誤修正等龐大工作追著跑，無法把資源投入本該投入的客戶價值創造與差異化功能開發。
    這就像把很久以前就發明出來的輪子，再從頭重做一次一樣。

    聰明運用 OSS，是把有限時間集中在價值最高工作上的策略。

2. **運用高品質程式碼與全球規模的知識**

    OSS 的程式碼在眾人注視下持續改良。
    在封閉開發流程中容易被忽略的程式錯誤，也能透過全世界使用者的回饋與貢獻及早發現並修正。

    例如 [公司名稱] 使用的 [主要 OSS 專案名稱]，每天都有大量 Pull Request 與 Issue 往來，持續進行資訊安全應對與效能改善。
    開發者能享有這些成果，並安心在自家服務之上累積新的價值。

3. **學習最新技術與現代開發方法**

    許多 OSS 專案在 GitHub 上公開進行，CI/CD 管線、自動測試、程式碼審查等現代開發做法自然而然被納入其中。
    開發者接觸這些做法，就能實務性地學到光靠公司內部學不完的最新實踐。

    尤其在 [自家公司關注的技術領域（例如：雲端原生或微服務）] 這類領域，OSS 專案正引領技術趨勢，參與本身就是提升技能的捷徑。

4. **解決問題的速度與彈性**

    專有軟體的錯誤修正與新功能發佈，取決於供應商的時程。
    相對地，OSS 的原始碼是公開的，必要時可以自行套用修補，依公司內部需求迅速應對。
    在急迫的資訊安全修正或客製功能實作上，這種彈性是很大的優勢。

5. **透過與社群協作而成長**

    透過貢獻開放原始碼，開發者能獲得與全世界優秀開發者協作的機會。
    透過提交錯誤回報與修正提案，可以接觸到單靠自己想不到的各種想法與解法。
    此外，把自己的變更提交到上游，也能持續受益於其他開發者後續的改善。

## 對管理階層的效益

策略性運用開放原始碼，也能為管理階層帶來許多效益。
以下舉出幾個特別重要的重點加以說明。

1. **成本最佳化與投資效率化**

    採用開放原始碼會改變企業的成本結構。
    支出將從授權費用這類持續性支出，轉向客製化與實作等依目的而定的開發投資。

    訓練、維護、支援等費用，不論是開放原始碼或專有軟體都會發生。
    專有軟體的情況下，還要在這些費用之外加上軟體使用費（授權費），成本結構往往較不透明。
    開放原始碼的情況下，軟體使用費本身並不需要，因此成本的組成會更清楚。

2. **強化人才培育**

    參與開放原始碼對開發者而言是絕佳的學習機會。
    管理階層讓員工參與開放原始碼專案，不只能培養技術能力，也能同時培養溝通能力、專案管理能力、團隊合作等軟實力。

    透過與全世界優秀開發者協作，員工能學到新技術與新做法，並擁有更寬廣的視野。
    這是傳統公司內部訓練無法獲得的寶貴經驗。

3. **分散風險與長期穩定性**

    使用專有軟體時，可能因供應商變更事業策略或結束營業，導致重要軟體的支援突然終止。
    開放原始碼的原始碼是公開的，因此可以依需要在內部繼續維護，或另尋替代的維護者。

    此外，開放原始碼社群不受營利目的束縛，相對容易以長期觀點持續改善軟體。
    這為組織的持續運作提供了重要的穩定性。

4. **強化招募與品牌**

    招募優秀開發者對許多組織來說是持續性的課題。積極參與開放原始碼專案，是對外展現組織技術能力的有效方式。開發者能透過實際的程式碼與專案的推進方式，事先了解該組織正在處理什麼樣的技術課題、採用什麼樣的工作方式。

    此外，成功開放原始碼專案的維護者常被視為業界領導者，這也有助於提升該維護者所屬組織的品牌價值。
